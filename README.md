# Прогнозування доходу українських підприємств

Проєкт прогнозує чистий дохід підприємства наступного року за річною фінансовою звітністю. Уся робота зібрана в [ua_revenue_forecast.ipynb](ua_revenue_forecast.ipynb).

## Ноутбук

Ноутбук має розділи 0–5 і виконує:

1. завантаження готової версіонованої панелі;
2. EDA та аналіз прапорців аномалій;
3. часову expanding-window валідацію;
4. єдине порівняння N1–N3 і M1–M3 на `all` та `clean`;
5. GroupKFold-діагностику, rolling-window та сегментний аналіз;
6. фінальні висновки й обмеження.

Сирі XML не розбираються під час стандартного запуску.

## Дані

- Джерело: [«Фінансова звітність підприємств (річна)»](https://data.gov.ua/dataset/6456ef0c-985c-4bb7-bf9d-16831161b416), Державна служба статистики України.
- `panel_v1.parquet` містить 602 042 рядки для 267 961 підприємства.
- Використано окремі річні файли 2021–2024 років і доступні пізні подання.
- Цілі обмежені 2024 роком; 2025 рік не використовується.
- У F1 лаг 2020 року наявний у 91,95% рядків.
- Панель опублікована в [Shnnapka/fin-zvit-ua](https://huggingface.co/datasets/Shnnapka/fin-zvit-ua).

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook ua_revenue_forecast.ipynb
```

Після відкриття виконайте **Restart Kernel and Run All**. Ноутбук спочатку шукає `out/panel_v1.parquet`, а за її відсутності завантажує `panel/panel_v1.parquet` із Hugging Face. Assert перевіряє, що це нова панель із непорожнім лагом F1.

На macOS для LightGBM потрібен OpenMP:

```bash
brew install libomp
```

## Валідація

| Фолд | Train за цільовим роком | Test |
|---|---|---|
| F1 | 2022 | 2023 |
| F2 | 2022–2023 | 2024 |

GroupKFold використовується лише як внутрішня діагностика. Фінальне рішення приймається за часовими F1–F2.

## Результати

`MAE_log` на всій популяції:

| Модель | F1 | F2 | Середнє |
|---|---:|---:|---:|
| N1 | **1.026** | **0.905** | **0.966** |
| N2 | 1.154 | 0.916 | 1.035 |
| N3 | 1.135 | 1.039 | 1.087 |
| M1 | 1.433 | 1.131 | 1.282 |
| M2 | 1.517 | 1.319 | 1.418 |
| M3 | 1.233 | 1.065 | 1.149 |

N1 також перемагає на чистій популяції із середнім `MAE_log=0.892`. Жодна навчена модель не має позитивного Skill в обох офіційних фолдах.

Rolling-window M3, навчена лише на 2023 році, отримує у F2 `MAE_log=0.886` і `Skill=0.021`. Це показує вплив часового режиму, але не замінює офіційний expanding-window результат.
